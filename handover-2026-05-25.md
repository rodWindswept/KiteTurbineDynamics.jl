## Key Findings & Lessons Learned

### 1. GLMakie Symbol-to-RGB Rendering Crash
In newer versions of Makie/GLMakie, passing a `Symbol` (like `:limegreen`, `:orange`, `:coral`) directly to a dynamic color observable inside a plot primitive or layout element (like `Toggle` or `Label`) causes the GUI to crash or freeze under animations.
*   **The Cause**: Makie establishes a reactive listener that attempts to write the Symbol directly into the underlying OpenGL shader uniform uniform-resolver (typed as `RefValue{RGB{Float32}}`), causing a `MethodError: Cannot convert an object of type Symbol to an object of type ColorTypes.RGB{Float32}`. For Toggles, it breaks during the active transition animation: `linear_interpolate(t, inactive_color_rgb, :limegreen)`.
*   **The Fix**: Always wrap dynamic colors and toggle state attributes inside the layout and plotting pipeline using `to_color(...)` (e.g. `to_color(:limegreen)`).

### 2. Active Winch & Backline Payout Physics
We verified that during the **Pitch Depower** scenario, the **Active Winch** behaves exactly as physically intended:
*   Because payout rate is throttled proportionally to `T_min` (halting when tethers drop towards slackness), the backline payout remains far below the nominal $25\text{ m}$ limit (e.g., settling at a few meters in a 10s run). 
*   In the 10s run, the rapid payout transient is violent, leaving tethers at $0\text{ N (SLACK)}$ in the final frame due to axial surge waves. In the 30s run, these waves have time to dissipate, letting the system settle into a stable preloaded state with a steady $\sim 45\text{ N}$ tension.

### 3. Real-Time HUD Telemetry Calculations
The HUD now dynamically computes the following three crucial metrics from the active ODE state vector `u` in real time:
*   **Lift Line ($T_{\text{cyan}}$)**: Derived from tethers `sys.sub_segs[end]` stretched distance.
*   **Backline ($T_{\text{back}}$ & payout)**: Payout is calculated geometrically relative to `back_L0_design`, and tension is solved via the 3D force balance at the Sky Anchor (balancing kite lift, cyan-line drag, and gravity).
*   **Gold Bridles**: Loops through the first `p.n_lines` sub-segments preceding the cyan line and averages their tensions.

### 4. Terminology: Elevation $\beta$ vs. Blade Pitch
Rotor aerodynamics uses $\beta$ for blade pitch angle, but Windswept/AWE codes historically use $\beta$ (beta) for the **shaft/lift line elevation angle** above the horizon. The main **Elevation $\beta$** slider governs shaft tilt, while the blade pitch coefficient scales via the Rotary Lifter "Pitch Factor" slider.

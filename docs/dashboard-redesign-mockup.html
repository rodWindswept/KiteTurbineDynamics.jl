What changed vs current HUD: the ~40-row monospace text wall is replaced by a cockpit status strip (operating point at a glance) + a three-column workspace. Safety is no longer buried — the tether FoS reads as a dedicated alarm zone in the strip and a full loads panel (D2) with an FoS gauge and an over-SWL marker on the tension colourbar. Bounded metrics use radial gauges; trends use sparklines (C2). Controls are collapsible workflow groups (E1) ordered config → lift → control → scenario → run. Theme is A1 Instrument (near-black, single cyan accent). Numbers shown are sample frame data from the over-loaded scenario for illustration.

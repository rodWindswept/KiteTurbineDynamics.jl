# KTDPaper_draft.md — Fact-Check
## 2026-06-23

### ❌ Definite errors

**1. Airfoil: S809 → NACA 4412 (line 41)**
The codebase consistently uses NACA 4412 (confirmed in aerodynamics.jl and bem.jl).
S809 appears nowhere in src/. This is the most important fix — wrong airfoil
undermines credibility.

**2. "Tveide TetherDragODESolver" (ref 11)**
Needs verification — does this repo/publication exist? If not, cite the specific
source for the 1/4 tether drag coefficient.

**3. "Moore, M.D. (2014)" (ref 9)**
The Moore CSR concept is referenced in the text as "NASA, 2014" but the ref says
"NIAC Phase I Final Report." The paper was actually published as a NASA technical
memorandum. Also the NASA CSR name in the paper draft uses "NASA NIAC Phase I" but
the original paper title and scope should be verified against the actual NASA
publication.

### ⚠️ Needs verification

**4. k_mppt = 615? (line 42)**
The code shows k_mppt_eff = p.k_mppt × λ² but params_10kw() has k_mppt=11.0.
In objective_v10.jl, the scaling uses p.k_mppt with λ_eff^2 but the actual
base value of p.k_mppt for the 50kW campaign needs confirmation. The 615 figure
appears in the sprint doc and paper but should be traceable to a specific
parameter set.

**5. bank_top=32°, bank_bottom=35° (lines 91-92)**
These aren't in best_design.json (the V10 Tight winner output). The JSON contains
r_hub, r_bottom, Do_top, t_over_D, target_Lr, n_lines, density_profile, aspect_ratio,
but no bank angles or blade scales. Where are λ_top, λ_bottom, bank_top, bank_bottom
sourced from? If from the DE vector (not the JSON summary), note the provenance.

**6. K1 graph numbers (line 61)**
Paper: "7,048 nodes, 9,775 edges, 586 individual paper graphs"
Sprint doc: "6,986 nodes, 9,730 edges, 533 graphs (469 with content)"
These are close but different — which is the final count? Was there a second pass?
The paper should cite the definitive, reproducible number.

**7. λ_bottom = 0.10 AT MIN (line 82)**
This implies the DE is pushing λ_bottom to its lower bound. If true, the optimum is
bound-constrained on this parameter, which means the true optimum lies outside the
search space. The paper already notes this for 5 parameters — is λ_bottom the 6th?
The table shows 5 parameters at bounds but λ_bottom=0.10 AT MIN suggests it's also
at a bound.

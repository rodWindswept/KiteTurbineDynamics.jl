## How a ruling reads

Each JSON entry carries an id, an anchor, a decision and a replacement. Four decisions read: keep, rewrite, drop and folded.

A rewrite swaps the anchor for the replacement text. A drop deletes the line, and the line must hold the anchor alone.

A folded entry records wording the author already moved into the source, so its anchor may be absent. The reader build refuses to run while any site reads unruled. It also fails when a ruled anchor leaves the draft.

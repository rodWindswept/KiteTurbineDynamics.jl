## How a ruling reads

Each JSON entry carries an id, an anchor, a decision and a replacement. Five decisions read: keep, rewrite, drop, folded and deferred.

A rewrite swaps the anchor for the replacement text. A drop deletes the line, and the line must hold the anchor alone.

A folded entry records wording the author already moved into the source, so its anchor may be absent.

A deferred entry targets text the draft file does not carry. Its anchor may be absent, and the rewrite applies when the text arrives. The caption set uses it, because the draft holds no caption text.

The reader build refuses to run while any site reads unruled. It also fails when a ruled anchor leaves the draft.

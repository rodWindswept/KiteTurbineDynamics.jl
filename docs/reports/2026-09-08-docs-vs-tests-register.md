## 4. VERDICT — findings for v13

1. **The 5 kW operating-point k has a doc-vs-code conflict at HEAD.** DECISIONS [2026-08-21] still documents k=5.39 as the gate alignment while the suite enforces 2.24 (test_campaign_k_alignment). Because k is the single most load-bearing campaign constant, the 08-21 entry must be amended with a SUPERSEDED pointer to the 08-24/09-04 entries. *Suggested: static doc-currency guard extending test_campaign_k_alignment to assert the DECISIONS text's `5.39` claim is annotated, or a stale-phrases.md entry "k=5.39 at 5 kW" → "2.24 (honest window)" — the doc_currency scanner already exists.*
2. **Signed P_gen [2026-08-20] is enforced only by a test that uses the banned abs() form at positive ω.** A reversion to `abs(ω)`/`max(ω,0)` masking passes the suite. *Suggested: static unit test that drives a reversed/regenerating state through `get_generator_torque` + a reader and asserts P_gen < 0 (acceptance or fast unit — pure function, fast).*

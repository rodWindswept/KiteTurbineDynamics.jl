For similar total power:


$$R^2 = R_1^2 + R_2^2 + R_3^2$$

Suppose $R_2 = k R_1$, and $R_3 = k R_2$ *(not necessary but simplifies analysis just to get some rough insight)*.

Then:


$$R_3 = k^2 R_1$$

So:


$$R_1^2 + (k R_1)^2 + (k^2 R_1)^2 = R^2$$

$$R_1^2 \{1 + k^2 + k^4\} = R^2 \implies R_1 = \{1 + k^2 + k^4\}^{-1/2} R$$

Mass ratio of rotors is:


$$M = \frac{R_1^3 + R_2^3 + R_3^3}{R^3} = \frac{R_1^3 + (k R_1)^3 + (k^2 R_1)^3}{R_1^3 \{1 + k^2 + k^4\}^{3/2}}$$

$$M(k) = \frac{1 + k^3 + k^6}{(1 + k^2 + k^4)^{3/2}}$$

If $k = 1$, the rotors are all the same size and:


$$M(k) = \frac{3}{3^{3/2}} = \frac{1}{\sqrt{3}} = 0.577$$

Mass saving is:


$$(1 - 0.577) \times 100\% = 42\%$$

The more unequal the rotor sizes, the less the mass saving and some combinations will even have a mass penalty.         



# Rotor blade mass ratio

$$k := 0, 0.01 .. 1$$

$$M(k) := \frac{1 + k^2 + k^4}{\left(1 + k^3 + k^6\right)^{\frac{3}{2}}}$$

This is realistic for the system only if all components are scaled with strict similarity e.g. the lines and the carbon tubes connecting the rotor blades etc.

A key assumption is that there is no detrimental interaction between the rotors at any spacing.

$$M(0.677) = 1 \qquad M(0.8) = 0.867$$

Unless $k > 0.677$ there is no mass saving predicted with the particular geometry modelled.

The most advantageous arrangement for saving mass is with $k = 1$, 3 rotors of the same diameter providing this works for tension/torque relationships and there is no adverse effect on power from rotor wake interactions.
